The Haywire curated marketplace

A curated catalogue of Haywire libraries, published as three subscribable feeds.

Paste one of these URLs into Add Source in the studio's Library Browser, or edit ~/.haywire/db/haybale_marketplace/marketplace.toml directly. Do not subscribe to two channels at once — they offer the same library names at different versions, and the studio treats that as a conflict on every refresh.

What being listed means — and does not

Merging a library into this catalogue asserts exactly three things:

  1. The distribution exists on PyPI and its wheel contains a valid haybale.toml.
  2. This name maps to this distribution — every row is generated by unzipping the wheel it points at, so it cannot describe one package and install another.
  3. For stable only: this version resolves alongside every other library in the set, and imports cleanly.

It asserts nothing about whether the code is safe, correct, maintained, or fit for your purpose. Nobody reads the source. Being listed here is not a security review — evaluate a library exactly as you would any package you install from PyPI.
