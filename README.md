# The Haywire curated marketplace

A curated catalogue of [Haywire](https://github.com/going-haywire/haywire)
libraries, published as three subscribable feeds.

This repo holds no library code and no packages. Every package is served by
PyPI. The repo holds a **list** of which libraries are in the catalogue, and
the tooling under `scripts/` that turns that list into feeds a Haywire studio
can subscribe to.

## Subscribing

A fresh Haywire install already subscribes to `stable`. To use a different
channel, paste its URL into **Add Source** in the studio's Library Browser, or
edit `~/.haywire/db/haybale_marketplace/marketplace.toml`.

**stable:** versions proven to install _together_

```TEXT
https://going-haywire.github.io/marketplace/stable/marketplace.toml
```

**latest:** the newest version of each library as of the _last catalogue release_

```TEXT
https://going-haywire.github.io/marketplace/latest/marketplace.toml
```

**edge:** whatever is _newest_ on PyPI right now

```TEXT
https://going-haywire.github.io/marketplace/edge/marketplace.toml
```

**Subscribe to one channel only.** They offer the same library names at
different versions, and the studio treats that as a conflict on every refresh.

How the channels differ, how to switch, and the archive of past releases:
[docs/subscribing.md](docs/subscribing.md).

## What being in this catalogue means — and does not

Merging a library into this repo asserts exactly three things:

1. The distribution exists on PyPI and its wheel contains a valid
   `haybale.toml`.
2. **This name maps to this distribution.** The row you see is generated by
   unzipping the wheel it points at, so it cannot describe one package and
   install another.
3. For the `stable` channel only: this version resolves alongside every other
   library in the set, and imports cleanly.

It asserts **nothing** about whether the code is _safe_, _correct_,
_maintained_, or _fit_ for your purpose. Nobody reads the source. Being listed
here is **not a security review**, and you should evaluate a library exactly as
you would any package you install from PyPI.

## Getting your library listed

Publish it to PyPI, then open an issue using the **Add a library** template.
A bot writes the registry entry, runs the checks and opens the pull request; a
curator merges.

Requirements, the PyPI setup, and what happens after merging:
[docs/getting-listed.md](docs/getting-listed.md). If your newest release is not
in `stable`, read
[stable-report.md](https://going-haywire.github.io/marketplace/stable-report.md).

## Repo layout

```text
registry/<dist-name>.toml   one file per catalogue member. Human-edited.
stable.constraints.txt      curator holds and exclusions, each with a reason
locks/stable.toml           the solved set, plus the Haywire release it was solved against
locks/latest.toml           the newest-at-release-time set
stable-report.md            why each library sits at the version it does
scripts/                    generator, solver, verifier
```

Everything under `https://going-haywire.github.io/marketplace/` is generated.
Do not edit it; edit the inputs and re-run.
